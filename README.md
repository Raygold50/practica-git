Práctica de Git y GitHub

Este repositorio ha sido creado como parte de las actividades de la asignatura de Fundamentos de Programación. Su objetivo es poner en práctica los conocimientos adquiridos sobre el uso de Git y GitHub para gestionar archivos y llevar un seguimiento de los cambios realizados en un proyecto.

Durante esta práctica se trabaja con la creación de repositorios, el registro de modificaciones mediante commits y la sincronización de archivos entre el equipo local y GitHub. También se incluye un archivo desarrollado en lenguaje C como parte de los ejercicios realizados durante el laboratorio.Este proyecto representa una primera aproximación al uso de herramientas de control de versiones, que resultan importantes para organizar y gestionar proyectos de programación.
